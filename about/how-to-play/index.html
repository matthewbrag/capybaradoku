How to play Capybaradoku

Three simple rules, one logical solution, zero guessing.

The rules

Every board is an N×N grid split into N coloured regions. Your goal is to place capybaras so that:

  • 🎨 One per regionExactly one capybara in each coloured patch.
  • ↔️ One per row & columnNever two capybaras in the same row or column.
  • 🚧 No touchingNo two capybaras next to each other — including diagonally.

That's it. It's the same core ruleset as Meowdoku and LinkedIn's Queens, just with capybaras. Every Capybaradoku level has exactly one solution, and you never have to guess — it can always be reasoned out.

How to make moves

Tap a cell to cycle through three states: a small note dot (to mark cells you've ruled out), a capybara, and empty again. You have three hearts — placing a capybara that breaks a rule costs one. Solve the board without running out and you win.

Strategy tips

1. Start with the tightest constraints

Look for a row, column, or region that only has one legal cell left — place there first, then see what it rules out.

2. Use "region confinement"

If a colour region's only possible cells all sit in one row (or column), then no other region can use that row — cross those cells off elsewhere.

3. Mind the no-touch rule

Placing a capybara blocks all eight surrounding cells. Diagonal neighbours are the ones people forget — use note dots to mark them.

4. Chase the chain reaction

Each placement usually forces the next. When you're stuck, re-scan every region for a new single-option cell created by your last move.
